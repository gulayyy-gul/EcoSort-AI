# 🌱 EcoSort AI

### Take a picture. Know where it belongs.

EcoSort AI is an AI-powered waste-sorting assistant that analyzes an image of a waste item and provides a waste category, confidence level, disposal guidance, safety warnings, eco tips, and reuse suggestions.

## ♻️ Waste Categories

EcoSort AI classifies waste into six categories:

- Recyclable
- Organic/Compostable
- Hazardous
- Electronic Waste
- General/Residual
- Reusable

## ✨ Features

- 📷 Image-based waste identification
- 🤖 AI-powered visual analysis
- ♻️ Six waste categories
- 📊 Confidence level
- 🧹 Practical disposal instructions
- ⚠️ Safety warnings for potentially hazardous waste
- 🌍 Region-aware guidance
- 💡 Eco-friendly tips
- 🔄 Reuse suggestions
- 📊 Session scanning statistics
- 🛡️ Responsible AI rules for uncertain images

## 🛠️ Technology

- Python
- Gradio
- Groq API
- Vision-capable AI model
- Pillow
- python-dotenv
